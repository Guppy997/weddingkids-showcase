- den Code ansehen, daraus lernen und über das Projekt schreiben

- eine App, einen Server, eine Website oder ein Angebot **WeddingKids** nennen oder einen Namen verwenden, der damit verwechselt werden kann
- Logo, Icons oder Screenshots für eigene Angebote verwenden

## Code weiterverwenden

Wer den Code weitergibt oder selbst betreibt, muss vorher:

1. den Namen „WeddingKids“ überall durch einen eigenen ersetzen, auch in `public/manifest.json`, `index.html` und den Texten der Oberfläche,
2. Logo und Icons in `public/` durch eigene ersetzen,
3. die Screenshots in `docs/screenshots/` entfernen oder durch eigene ersetzen.

Ein Hinweis wie „basiert auf dem WeddingKids-Showcase“ ist erlaubt, solange klar bleibt, dass es kein Angebot von WeddingKids ist.
